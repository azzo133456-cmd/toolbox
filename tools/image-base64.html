使用說明

    
「Data URI」可以直接貼到 CSS 的 background-image:url(...) 或 HTML 的 <img src="...">;「純 Base64」則是拿掉前綴的原始編碼內容。還原時如果貼的是完整 Data URI,系統會自動偵測格式;若只有純字串,需要手動選擇格式。
