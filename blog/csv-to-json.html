如何免費把 CSV 轉成 JSON?3 步驟線上教學

發布日期:2026-08-06

工程師串接 API、寫測試資料時,常常需要把 Excel 或 CSV 表格轉成 JSON 格式。這篇教你不用寫程式,3 步驟在瀏覽器完成轉換。

步驟 1:準備 CSV 內容

從 Excel 或 Google Sheets 複製表格內容(含標題列),或是直接準備一個 .csv 檔案。例如:

姓名,年齡,城市
小明,25,台北
小華,30,高雄

步驟 2:貼上並轉換

打開表格格式轉換工具,把 CSV 內容貼到輸入框,來源格式選擇 CSV,目標格式選擇 JSON,工具會即時轉換,不需要上傳檔案、不需要註冊帳號。

轉換後會得到:

[
  { "姓名": "小明", "年齡": "25", "城市": "台北" },
  { "姓名": "小華", "年齡": "30", "城市": "高雄" }
]

步驟 3:驗證與美化 JSON

如果拿到的 JSON 是別人給的、或想確認格式是否正確,可以貼到 JSON 格式化工具,它會自動美化排版、標出錯誤位置,方便除錯。

常見問題

Q:資料會不會被上傳到伺服器? 不會。這個網站的所有工具都在瀏覽器本機執行 JavaScript 完成轉換,資料不會傳到任何後端伺服器。

Q:CSV 裡面有中文或逗號會出錯嗎? 工具有處理常見的雙引號包覆欄位(例如欄位內容包含逗號時會自動用 "..." 包住),多數情況可以正常解析。

Q:可以反過來把 JSON 轉成 CSV 嗎? 可以,同一個表格格式轉換工具支援 CSV、TSV、JSON、Markdown、HTML 表格互相轉換,來源跟目標格式都可以自由切換。
