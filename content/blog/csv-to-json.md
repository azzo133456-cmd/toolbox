很多人一聽到「格式轉換」就以為要寫 Python 或裝套件(`csvtojson`、`pandas`...),其實多數情況下你只是想把手上的表格丟進程式測試,或貼給前端當假資料——這種一次性的轉換,根本不需要寫程式,3 步驟就能在瀏覽器完成。

## 你可能遇到這 3 種情境

**情境 1:工程師準備測試資料**
API 開發到一半,需要一批假資料丟進資料庫測試,手上只有 Excel 匯出的 CSV,懶得為了一次性任務寫轉換腳本。

**情境 2:前端要 mock API 回應**
後端還沒好,前端想先用假資料串接畫面,拿到的規格是一份 CSV 表格,需要轉成 `.json` 檔案放進專案。

**情境 3:資料處理與交換**
跟其他系統對接,對方只吃 JSON 格式,但你手邊的原始資料是 Excel/CSV 報表。

不管哪一種,流程都一樣。

## 3 步驟轉換

### 步驟 1:準備 CSV 內容

從 Excel 或 Google Sheets 複製表格內容(記得連標題列一起複製),或準備一個 `.csv` 檔案內容,例如:

```
姓名,年齡,城市
小明,25,台北
小華,30,高雄
```

### 步驟 2:貼上並選擇格式

打開[表格格式轉換工具](../tools/table-converter.html),把內容貼到輸入框,來源格式選 CSV、目標格式選 JSON,右側會即時顯示結果——不用按送出、不用上傳檔案、也不用註冊帳號。

轉換後會得到:

```json
[
  { "姓名": "小明", "年齡": "25", "城市": "台北" },
  { "姓名": "小華", "年齡": "30", "城市": "高雄" }
]
```

### 步驟 3(選用):驗證格式是否正確

如果 JSON 是別人給你的、或你想確認語法有沒有問題,貼到 [JSON 格式化工具](../tools/json-formatter.html),它會自動美化排版並標出錯誤位置,比肉眼找漏掉的逗號快很多。

## 常見踩雷點

- **欄位裡有逗號**:如果儲存格內容本身包含逗號(例如地址「台北市, 大安區」),記得用雙引號包住該欄位,例如 `"台北市, 大安區"`,否則會被誤判成多一欄
- **中文亂碼**:如果原始檔案是從舊版 Excel 存成 CSV,編碼可能是 Big5 而非 UTF-8,貼上前建議用文字編輯器另存成 UTF-8 編碼
- **標題列缺漏**:少了標題列,轉出來的 JSON 欄位名稱會變成 `col1`、`col2` 這種預設值,記得確認第一行是欄位名稱

## 常見問題

**Q:資料會不會被上傳到伺服器?**
不會。這個網站的所有工具都在瀏覽器本機用 JavaScript 執行轉換,資料不會離開你的裝置,也不會被記錄。

**Q:可以反過來把 JSON 轉成 CSV 嗎?**
可以,同一個[表格格式轉換工具](../tools/table-converter.html)支援 CSV、TSV、JSON、Markdown、HTML 表格互相轉換,來源跟目標格式都能自由切換。

**Q:資料量很大(上千列)會卡住嗎?**
工具在瀏覽器記憶體內處理,一般報表等級(數千列)沒問題;如果是數十萬列的大型檔案,建議還是用程式腳本處理較穩定。
